# 📊 Department & Region-wise Expense Analysis Dashboard

Analyzed 1500+ transactional records to evaluate organizational spending patterns across departments, regions, and product categories.

## 🔍 Key Analysis
- Department-wise and region-wise expense breakdown  
- Category-level cost distribution  
- Identification of top-spending departments  

## 📈 Key Insights
- HR contributes ~28.6% of total spend, with highest concentration in West region  
- Software is the top contributing category overall, driven primarily by Procurement  
- Procurement shows high software-related spending, indicating reliance on digital tools  

## 💡 Recommendations
- Review software subscriptions to reduce recurring costs  
- Analyze high-spending departments for cost optimization  
- Monitor regional spending for balanced allocation  

## 🛠 Tools Used
- Excel (Pivot Tables, Slicers, Charts)
